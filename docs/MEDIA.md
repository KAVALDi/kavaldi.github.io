# Игровые спрайты и медиа

## Стратегия

Сайт живёт в собственном репозитории и не зависит от форка игры. Спрайты попадают на него **контролируемым импортом отдельных файлов**:

1. Нужный PNG копируется из игрового репозитория в `media/<проект>/` приватного хранилища.
2. Рядом кладётся файл атрибуции `<имя>.png.yaml`:

```yaml
license: CC-BY-SA-3.0
author: "Строка copyright из meta.json набора спрайтов"
source: https://github.com/red-star-server/RedStar/tree/master/Resources/Textures/…
note: Необязательное пояснение
```

3. Экспорт копирует в `content/media/` только файлы, на которые ссылается опубликованная запись (`![подпись](media/…)`) или витрина проекта. Файл без `license` и `source`/`author` останавливает экспорт с понятной ошибкой.
4. Страница "Атрибуция и лицензии" строится из этих же сведений автоматически.

Почему так: ссылки не ломаются при изменениях в игре, объём сборки мал (сейчас 14 файлов по 32×32), лицензия и автор каждого файла зафиксированы в момент импорта. Весь каталог ресурсов игры не копируется.

Отклонено: брать картинки прямыми ссылками из репозитория игры (ломаются при переименовании, нет контроля атрибуции), а также git-подмодуль с игрой (сотни мегабайт ради десятка иконок).

## Витрина проекта на главной

Поле `showcase` в файле проекта описывает крупный блок первого экрана:

```yaml
showcase:
  eyebrow: Space Station 14 · RedStar
  title: Как устроено пчеловодство в SS14
  text: Короткий абзац
  cta: Читать о первой пасеке
  entity: art-beekeeping          # куда ведёт кнопка. Запись должна быть опубликована
  tint: "#E8A21C"                 # цвет для слоёв с tint
  layers:                         # главный спрайт: слои снизу вверх
    - { file: media/redstar/beehive-frames-4.png }
    - { file: media/redstar/beehive-honey-4.png, tint: true }
  flyers:                         # анимированные листы кадров: cols × rows
    - { layers: [media/redstar/bees-worker-base.png, media/redstar/bees-worker-wings.png], cols: 3, rows: 2, count: 4 }
  items:                          # ряд небольших предметов с подписями
    - { label: Соты, layers: [{ file: media/redstar/honeycomb-icon.png }] }
```

Слои с `tint: true` окрашиваются умножением, как это делает игра с обесцвеченными слоями. Цвет мёда на витрине подобран для показа и не взят из прототипов игры. У листов кадров проигрывается первая строка.

Блок показывается у первого по порядку публичного проекта, у которого есть `showcase`.

## Что сейчас на сайте

Спрайты пчеловодства RedStar: улей с рамками и мёдом, рабочая пчела, матка, соты, воск, рамка, дикий улей. Все под CC BY-SA 3.0. Часть основана на спрайтах tgstation, часть нарисована автором: точные строки авторства перенесены из `meta.json` и показаны на странице атрибуции.

## Режим "как в игре"

Окно игрового руководства с игровыми шрифтами в новый сайт не переносилось. У статьи есть поле `ingame_url`. Сейчас оно ведёт на прежний сайт, где такое руководство уже опубликовано. Когда понадобится собственное представление, его стоит делать отдельной страницей со своей таблицей стилей, не смешивая с дизайн-системой Wiki.
