## Не проверялось

- **Публикация на GitHub Pages.** Сайт опубликован 2026-11-12 через GitHub Actions. Страницы отвечают, внешний вид опубликованной версии в браузере не проверялся.
- **Obsidian.** Хранилище совместимо по формату, но в самом приложении не открывалось.
- **Физический телефон**, другие браузеры, программы чтения с экрана.
- **Большие объёмы.** Поиск совпадений перечитывает все источники. На сотнях записей не замерялся.
- **Правка одной записи с двух устройств** и синхронизация хранилища между компьютерами.
- **AI-слой**: провайдеров нет, есть только контракт.
- **Поле выбора файла и перетаскивание** в студии: код есть, руками не проверялось (импорт шёл вставкой текста и через командную строку).
