# Developer Knowledge Hub

Персональный сайт разработчика и инженерная база знаний в одном рабочем процессе.

- **Публичный сайт**: проекты, Wiki, дорожные карты, каталог механик и решений, реальная активность GitHub.
- **Приватная база знаний**: папка с Markdown-файлами вне этого репозитория: идеи, решения, исследования, их связи, состояния и происхождение.
- **Студия**: локальный интерфейс: вставить обсуждение или заметку → увидеть, что уже есть по теме → отредактировать черновик → одобрить → отдельно разрешить публикацию → собрать сайт.

Этот репозиторий публичный. В нём лежат инструменты, генератор сайта и **только те** материалы, которые владелец разрешил публиковать (`content/`). Сама база знаний сюда не попадает.

## Быстрый старт

Нужен Node.js 20 или новее.

```bash
npm ci
```

```bash
npm test
```

Попробовать на тестовых (вымышленных) данных, ничего не настраивая:

```bash
npm run demo:init
```

```bash
npm run demo:studio
```

Студия откроется на `http://127.0.0.1:4319/`. Тестовые заметки для импорта лежат в `examples/notes/`.

## Работа с настоящей базой

По умолчанию хранилище ищется в соседней папке `../knowledge`. Другой путь задаётся переменной `HUB_STORE` или файлом `hub.local.json` (`{ "store": "D:/knowledge" }`).

```bash
npm run hub -- init
```

```bash
npm run studio
```

Сквозной путь от заметки до сайта:

1. **Импорт и разбор**: вставьте текст или перетащите файл, нажмите "Разобрать".
2. Проверьте предложенный проект, найденные совпадения и действие (создать, обновить, связать, отложить, пропустить).
3. Отредактируйте черновик и нажмите "Одобрить". Запись сохранена, но остаётся приватной.
4. На странице записи нажмите "Разрешить публикацию…" это отдельное действие.
5. **Выпуск сайта** → "Собрать сайт и проверить". Экспорт, сборка и проверка приватности. Ниже откроется предпросмотр.
6. Закоммитьте `content/` и отправьте в GitHub: см. [docs/WORKFLOW.md](docs/WORKFLOW.md).

Всё то же доступно из командной строки: `npm run hub -- help`.
